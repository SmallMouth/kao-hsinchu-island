# 專案架構

本專案使用 Vite 與 Three.js，呈現 12 個主題、90 項施政整理資料。城市位置與人物活動均為互動示意。

## 模組

- `src/main.js`：成果清單、搜尋、狀態篩選、詳細卡片、來源說明與場景初始化。
- `src/scene.js`：城市模型、光線、相機、主題選取、鏡頭跟隨、拍照模式與資源釋放。
- `src/route-logic.js`：每島環狀步道、鄰島橋、最短路徑、距離取樣及途中改道。
- `src/city-life.js`：28 位角色、10 條示意路線、搬運徽章、人物步態、停留、巡遊與日誌。
- `src/life-ui.js`：角色外觀、行程、拍照、協作線控制及城市概況介面。
- `src/data.json`：分類與原文項目；資料規則見 `content-notes.md`。

## 行動與顯示

人物與路線使用同一份步道圖。途中更換目的地時，由當前路段接回路網，不直接跳到新位置。角色抵達目的地後可停留、折返、繼續巡遊或擺出指定姿勢。暫停時不推進模擬時間、人物位置、步態與日誌。

角色外觀支援姓名、身分、顏色、髮型、衣款、帽子、配件與體型。設定以 `hsinchu-island-avatar:v1` 保存在目前瀏覽器的 localStorage；讀取時檢查資料類型、列舉、顏色與數值範圍。資料不會上傳。

協作線及出發、抵達事件是互動模擬，不代表已查證政策因果關係、政府事件或實際人流。

## 可用性與測試

介面支援手機清單、鍵盤操作、對話框焦點還原及減少動態效果設定。裝置無法使用 WebGL 時，仍可從文字清單閱讀全部內容。

`npm test` 檢查資料完整性、路徑與角色狀態；`npx playwright test` 檢查桌面及手機互動；`npm run build` 產生靜態網站。部署輸出位於 `dist/`。

## 城市背景

`src/city-backdrop.js` 建立非互動的城市街廓、校園式建築、公園綠帶及遠景丘陵。以固定亂數種子保持配置一致，按幾何與材質批次繪製，背景不加入角色及主題的點選集合。場景釋放時一併清除背景資源。背景為視覺示意，非實際地理模型。

## 島嶼尺寸與設施

`src/island-layout.js` 統一島嶼中心、地塊倍率、環島步道半徑及相鄰島距離，供場景與路徑圖共用。地塊寬度為初版的 1.3 倍，建築與角色保留原尺寸；`src/island-details.js` 在增加的腹地配置各主題的生活設施，環狀步道保留通行空間。

`src/baseball-stadium.js` 為環境休閒島建立棒球場示意模型，包含條紋草皮、紅土內野、壘包、看台、計分板與照明塔。沿用場景幾何與材質的釋放流程，外圈保留原角色步道；不修改施政資料內容。

`src/river-weather.js` 提供彎曲河道、兩側岸線、流動波紋與飄動雲層。天氣按鈕切換晴時多雲、晴天及陰天；雲量會調整光照，屬視覺示意，未連接即時氣象資料。水流與雲層共用場景暫停及減少動態效果設定。

`src/wind.js` 提供共用的示意風向、陣風強度及連續位移。島上樹木以樹根為軸擺動，背景只更新樹冠實例；河紋與雲層沿相同風向移動，暫停或隱藏頁面時停止風效時間。

樹木使用固定樹根、上下兩段樹幹及分枝樹冠。`sampleTreeWind` 讓樹幹、上層樹冠和枝葉採不同相位，呈現傾斜、延遲回彈及細部顫動；背景樹冠仍採實例批次繪製。

風場以固定世界座標方向統一驅動樹木、河面風紋與雲層。樹木採簡化阻尼彈簧的穩態響應，個體差異僅影響柔軟度，不改變風向與陣風時序；雲沿單一路徑循環並在端點縮小，風紋到岸邊漸隱。這是視覺物理近似，不是流體或氣象模擬。

`src/school-campus.js` 建立通學步道島的磚色校舍、中央圓弧樓梯塔與植栽庭院，外圈保留通學人行道及角色路徑。模型依提供照片的可見特徵簡化，不代表精確建築尺寸。
