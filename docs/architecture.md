# 專案架構

本專案使用 Vite 與 Three.js，呈現 12 個主題、90 項施政整理資料。城市位置與人物活動均為互動示意。

## 模組

- `src/main.js`：成果清單、搜尋、狀態篩選、詳細卡片、來源說明與場景初始化。
- `src/scene.js`：城市模型、光線、相機、主題選取、鏡頭跟隨、拍照模式與資源釋放。
- `src/route-logic.js`：每島環狀步道、鄰島橋、最短路徑、距離取樣及途中改道。
- `src/city-life.js`：28 位角色、10 條示意路線、搬運徽章、人物步態、停留、巡遊與日誌。
- `src/life-ui.js`：角色外觀、行程、拍照、協作線控制及城市概況介面。
- `src/data.json`：分類與原文項目；資料規則見 `content-notes.md`。

## 行動與顯示

人物與路線使用同一份步道圖。途中更換目的地時，由當前路段接回路網，不直接跳到新位置。角色抵達目的地後可停留、折返、繼續巡遊或擺出指定姿勢。暫停時不推進模擬時間、人物位置、步態與日誌。

角色外觀支援姓名、身分、顏色、髮型、衣款、帽子、配件與體型。設定以 `hsinchu-island-avatar:v1` 保存在目前瀏覽器的 localStorage；讀取時檢查資料類型、列舉、顏色與數值範圍。資料不會上傳。

協作線及出發、抵達事件是互動模擬，不代表已查證政策因果關係、政府事件或實際人流。

## 可用性與測試

介面支援手機清單、鍵盤操作、對話框焦點還原及減少動態效果設定。裝置無法使用 WebGL 時，仍可從文字清單閱讀全部內容。

`npm test` 檢查資料完整性、路徑與角色狀態；`npx playwright test` 檢查桌面及手機互動；`npm run build` 產生靜態網站。部署輸出位於 `dist/`。
